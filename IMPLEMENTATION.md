# Implementation notes

Paper: *Exploring speech style spaces with language models: Emotional TTS without
emotion labels* (Suresh Chandra, Du, Sisman — arXiv:2405.11413).

Scope: TEMOTTS only (Stage I, Stage II, text-only inference). The baselines
(FastSpeech2, VITS) are not included.

## What the paper specifies, and where it is in the code

| Paper item | Paper value | Where in code |
|---|---|---|
| Backbone | FastSpeech2, ESPnet2 implementation | `temotts/models/fastspeech2.py` (port of `espnet2/tts/fastspeech2`) |
| Style space | GST (ESPnet2 reference encoder + style-token layer), conditions the encoder output | `temotts/models/gst.py` |
| # style tokens | **16** (best of 8/16/32/64) | `configs/stage1.yaml: gst_tokens` |
| Stage I data | LJSpeech + emotional TTS dataset (skit-ai, 1 female speaker), 22.05 kHz | `scripts/prepare_corpus.py` |
| Split | train/val/test = **18:1:1** | `scripts/prepare_corpus.py` |
| Features | hop 256, 80 mel bins | `temotts/audio.py` |
| Durations | Montreal Forced Aligner | MFA 3.x, `english_us_arpa`, `configs/mfa_align.yaml` |
| Optimiser | Adam, β1=0.9, β2=0.999, ε=10e-9, Noam, 4000 warm-up, lr=10e-4 | `temotts/optim.py` |
| Model selection | best validation loss | `train_stage1.py`, `train_stage2.py` |
| Emotion LM | `michellejieli/emotion_text_classifier` (DistilRoBERTa-base) | `temotts/lm.py` |
| Data pruning threshold | **P_th = 0.7** on the dominant-class probability | `configs/stage2.yaml: pruning.p_th` |
| Text embedding | mean pooling over the LM's last layer (768-d) | `temotts/lm.py` |
| Adaptation module | FC layers 772, 600, 500, 400, 300, 200, 100, 50, 40, 16 + ReLU | `temotts/models/adaptation.py` |
| Stage II target | GST weights predicted by the trained reference encoder (soft labels) | `scripts/stage2_prepare.py` |
| Stage II loss | categorical cross-entropy with soft labels | `train_stage2.py` |
| Inference | text → LM → adaptation → GST weights → style embedding → FS2 → vocoder | `temotts/pipeline.py`, `synthesize.py` |
| Vocoder | pretrained Parallel WaveGAN trained on LJSpeech (`ljspeech_parallel_wavegan.v1`) | `temotts/vocoder.py` |

No emotion labels are used for training. The dataset's folder names
(angry/happy/…) are used only to stratify the 18:1:1 split and to colour
t-SNE plots / group the audio samples logged to W&B.

## Details the paper leaves open, and the choices made here

1. **GST attention heads** *(confirmed by the authors: 1 head)*. ESPnet's default
   is 4 heads, which gives 4 weight vectors over the tokens, but the adaptation
   module predicts one 16-way distribution. With `gst_heads: 1`, "the GST
   weights" are a single softmax over 16 tokens, and the inference style
   embedding `Σ_k w_k · e_k` is exactly the training-time one. `gst_heads: 4`
   is also supported (head-averaged targets, predicted weights shared across
   heads at inference).
2. **Adaptation module widths** *(confirmed by the authors)*. The text says
   "eight FC layers" but lists ten sizes, and the LM output is 768-d, not 772.
   Every listed size is a layer: `768 → 772 → 600 → 500 → 400 → 300 → 200 →
   100 → 50 → 40 → 16`, ReLU between layers, logits at the end
   (`configs/stage2.yaml: model.hidden`).
3. **Learning rate and ε.** Taken literally: `10e-4 = 1e-3` is the **peak** of a
   Noam warm-up/inverse-sqrt schedule (ESPnet `WarmupLR` form:
   `lr · warmup^0.5 · min(step^-0.5, step·warmup^-1.5)`), and `ε = 10e-9 = 1e-8`.
   The same optimiser is used for both stages.
4. **FastSpeech2 hyper-parameters** come from ESPnet2's
   `egs2/ljspeech/tts1/conf/tuning/train_fastspeech2.yaml` (adim 384, 2 heads,
   4+4 transformer layers with conv1d FFN k=3, dropout 0.2, variance
   predictors, Dio pitch + frame energy, token-averaged, global-MVN normalised,
   grad clip 1.0).
5. **Speakers.** A basic speaker lookup table (`nn.Embedding(2, 384)`, ESPnet
   `sid_emb`, added to the encoder output like GST) picks between LJSpeech (0)
   and the emotional speaker (1). Text-only inference uses speaker 1, the voice
   Stage II was trained on.
6. **Phone set and G2P.** MFA `english_us_arpa` acoustic model with a corpus
   lexicon generated by `g2p_en` (stress-marked ARPAbet). The same G2P runs at
   inference, so training and inference phone sequences match. Leading and
   trailing silences are trimmed; inner silences become `sp` tokens.
7. **Mel features** replicate Parallel WaveGAN's `logmelfilterbank` (n_fft 1024,
   win 1024, hop 256, fmin 80, fmax 7600, log10), so the pretrained LJSpeech
   PWG can vocode directly. TTS features are global-MVN normalised (ESPnet
   style) and de-normalised before vocoding.
8. **Reference encoder padding.** ESPnet runs the GRU over zero-padded frames.
   Here the GRU is packed by length, so an utterance's GST weights do not depend
   on what else is in its batch. This matters for the Stage II targets.
9. **Stage II training length.** Not given. Default: up to 20k steps, keeping
   the checkpoint with the best validation soft-CE.
10. **Missing audio.** Emotion folders whose metadata rows have no wav are
    skipped. In the copy of the dataset used here, `surprise` had metadata but
    no audio, so 8 of the 9 emotions (2,843 utterances) were used.

## Weights & Biases logging

One run per stage, project `temotts` (override with `WANDB_PROJECT` /
`WANDB_ENTITY`, or set `WANDB_MODE=offline`).

- Stage I: all loss terms (mel L1 before/after postnet, duration, pitch,
  energy), lr, grad-norm, steps/s; at each validation: val losses, GT vs
  predicted mel images, GST weight heatmap, and PWG-vocoded audio (style from
  the ground-truth reference) for fixed val utterances from LJSpeech and from
  each emotion folder.
- Stage II: train/val soft-CE, KL, top-1 token agreement, utterances kept per
  emotion folder, t-SNE of GST weights vs text embeddings (a replica of the
  paper's Fig. 2), and text-only synthesized audio for the paper's example
  sentences.
